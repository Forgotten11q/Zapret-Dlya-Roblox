# Zapret-Dlya-Roblox
Не официальная пересборка Zapret для правильной работы Roblox на территории Российской Федирации.
Все скачивается только на ваш страх и раск. Ничего настраивать уже не нужно, все сделано за вас. 
Проверяйте подходящий вам general.bat через service.bat (в открывшейся командной строке пишете 12, открывается дополнительное окно, в него вписываете 1 и 1, ждете окончания проверки general.bat далее запускаете подходящий вам .bat) и пользуйтесь.
Для автоматического запуска Zapret при старте вашего устройства можете [ознакомиться тут](https://github.com/flowseal/zapret-discord-youtube#%E2%84%B9%EF%B8%8F%D0%BA%D1%80%D0%B0%D1%82%D0%BA%D0%B8%D0%B5-%D0%BE%D0%BF%D0%B8%D1%81%D0%B0%D0%BD%D0%B8%D1%8F-%D1%84%D0%B0%D0%B9%D0%BB%D0%BE%D0%B2)
