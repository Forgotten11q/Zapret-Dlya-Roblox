# Zapret-Dlya-Roblox
ЭТО НЕ ОФИЦИАЛЬНАЯ ВЕРСИЯ Zapret для корректной работы Roblox.
Ничего настраивать уже не нужно, все сделано за вас.
Проверяйте подходящий вам файл general (alt).bat через service.bat. В открывшейся командной строке пишете 12, открывается дополнительное окно, в него вписываете 1 и 1, ждете окончания проверки general (alt).bat, далее запускаете подходящий вам .bat) и пользуйтесь.
Для запуска Zapret при старте вашего устройства: запустите service.bat, затем нажмите 1 и выберите нужный вам .bat (например, general (ALT13).bat это 13, у всех по-разному).
